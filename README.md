### 製品説明（具体的な製品の説明）
数学のペーパーテストやワークの答案を撮影・送信すると、AIが問題文・解答・途中式を読み取る。講師が読み取り結果とAIの生成した模範解答を確認した後、符号の扱い・分配法則・同類項の整理など、つまずいている要素を根拠とともに示し、理解を深めるためのアドバイスを提示する。
