## 製品概要
数学のつまずいた点を見つけるウェブアプリ

### 特長
#### 1. 特長1
専用のデータセットを使った原因を予測するモデルを利用しており、ウェブ検索を用いて推論を行う一般的な生成AIよりもそのミスに対して統計的に有意な要因を推測することが可能である。またセキュリティの側面においても外部アプリへの依存度を減らすことでハッキングや情報漏洩のリスクを抑えることも可能である。
#### 2. 特長2
問題の正誤だけでなく途中式も確認して分析することができる。これにより、ミスの発生個所を特定することが可能となり、誤概念の推定を高精度で行えるようになる。
#### 3. 特長3
手書きの写真から数式を抽出し、自動で「問題」、「途中式」、「解答」へ振り分けることができる。これにより、専用の教材を必要とせず、あらゆる教材に対応可能となっている。

### 背景(製品開発のきっかけ、課題等）
大学生が塾講師として指導する場面では、教育を専門に学んでいない学生も、生徒の理解度に合わせた説明や学習計画を求められる。講師ごとの指導経験や教え方の違いによって、指導の質にばらつきが生じやすい点に着目した。
特に、復習する内容や宿題を講師の裁量で決める際には、「生徒が何を理解できていないのか」「どの問題から取り組ませるべきか」を判断する難しさがある。答案の正誤だけではつまずきの背景を把握しにくく、経験の浅い講師にとって負担になり得る。
そこで、数学の答案から細かな苦手要素を分析し、確認問題や復習の候補を提示するアプリを考案した。講師が生徒の状況を把握し、復習や宿題を選ぶための判断材料を提供することで、大学生講師の指導を支え、生徒一人ひとりに合った学習支援につなげることを目指す。

### 製品説明（具体的な製品の説明）
本製品は、生徒の数学の答案写真から、つまずいている考え方を推定し、塾講師や家庭教師の指導を支援するWebアプリである。
答案を撮影・アップロードし、読み取り結果を確認すると、誤答や途中式をもとに、ミスの原因・つまずきの単元・指導時の声かけを日本語のレポートにまとめる。計算問題に加えて文章題にも対応し、必要に応じて講師が正答や採点結果を入力して分析することができる。
答案に表れた誤りの背景を整理することで、講師が生徒の理解度を把握し、次の指導につなげられることを目指している。

### 解決出来ること
計算途中のミスのポイントの傾向を発見することで勘違いしている部分を発見することができるので，数学の勉強をサポートすることができる．具体的には以下の3点が挙げられる.
- **生徒のつまずきを具体的に把握できる**  
  正誤や合計点だけでは分かりにくい、計算規則や考え方の理解不足を、答案の根拠とともに確認できる.
- **復習・宿題を選ぶ際の迷いや負担を減らせる**  
  苦手要素に応じた確認問題や復習候補を提示し、生徒の状況に合う課題を選びやすくする.
- **講師の経験による指導のばらつきを抑える手がかりになる**  
  「苦手要素の確認→復習→類題での理解確認」という共通の手順を示し、経験の浅い大学生講師でも指導を組み立てやすくする.

### 今後の展望
- **現場での有用性の検証**  
  実際の個別指導塾で試験導入し、通常の指導や汎用AIを利用する場合と比較して、分析の適切さ・使いやすさ・講師の負担軽減効果を検証する。
- **分析から指導・復習への接続**  
  生徒への問いかけ、確認問題、苦手要素に応じた復習内容の提示を充実させる。また、普段使用する教材と連携し、具体的な宿題を選びやすい仕組みを目指す。
- **診断精度と信頼性の向上**  
  学習に使用していない日本語の手書き答案で評価し、講師による訂正を通じて改善する。答案から確認できる誤りと原因の仮説を区別し、根拠が不足する場合は追加の確認を促す。
- **学習履歴と指導内容の共有**  
  後日の類題で理解の定着を確認できるようにし、講師間で分析結果や指導内容を引き継げる仕組みを整える。
- **安定した運用と情報管理**  
  固定URLでの常設公開、講師ごとのログイン、答案データの保存・削除・外部送信ルールを整備する。通信障害やAPI利用上限への対応、動作速度・運用費用の改善、問い合わせ体制の整備を進める。
  
### 注力したこと（こだわり等）
- **数学の誤概念データセットを用いた独自推論モデルの構築**  
  問題文・正答・生徒の誤答から、つまずきの原因候補を推定するモデルを構築した。日本の学習単元に合わせて候補を絞り込み、講師が理解しやすい日本語のレポートにつなげている。
- **手書き答案から、誤りを保ったまま数式を抽出すること**  
  画像認識APIを活用し、問題文・途中式・最終解答を分けて抽出する処理を設計した。生徒の誤答が正しい式に補正されないよう読み取り方を工夫し、元画像との照合・修正や、範囲を指定した再読み取りにも対応した。
- **数式の検証と誤概念推論の組み合わせ**  
  計算エンジンによる正答・途中式の検証と、独自モデルによる誤概念候補の推定を組み合わせた。答案上で確認できる誤りと、背景にある考え方の候補を、講師が照らし合わせて判断できる構成を重視した。
- **紙の教材を使う大学生講師に合わせた設計**  
  普段のワークやテストの答案写真を入口に、つまずきの単元・原因候補・指導時の声かけを整理する。経験の浅い講師が、生徒に何を確認し、どう説明するかを考える手がかりになることを目指した。
