## 製品概要
数学のつまづいた点を見つけるウェブアプリ
### 背景(製品開発のきっかけ、課題等）
大学生が塾講師として指導する場面では、教育を専門に学んでいない学生も、生徒の理解度に合わせた説明や学習計画を求められる.講師ごとの指導経験や教え方の違いによって、指導の質にばらつきが生じやすい点に着目した.
特に、復習する内容や宿題を講師の裁量で決める際には、「生徒が何を理解できていないのか」「どの問題から取り組ませるべきか」を判断する難しさがある.答案の正誤だけではつまずきの背景を把握しにくく、経験の浅い講師にとって負担になり得る.
そこで、数学の答案から細かな苦手要素を分析し、確認問題や復習の候補を提示するアプリを考案した.講師が生徒の状況を把握し、復習や宿題を選ぶための判断材料を提供することで、大学生講師の指導を支え、生徒一人ひとりに合った学習支援につなげることを目指す.
### 製品説明（具体的な製品の説明）
数学のペーパーテストやワークの答案を撮影・送信すると、AIが問題文・解答・途中式を読み取る.講師が読み取り結果とAIの生成した模範解答を確認した後、符号の扱い・分配法則・同類項の整理など、つまずいている要素を根拠とともに示し、理解を深めるためのアドバイスを提示する.
### 特長
#### 1. 特長1
画像を送るだけで文字を認識して結果を出してくれる
#### 2. 特長2
問題の正誤だけでなく途中式も確認して分析
#### 3. 特長3
専用のデータセットを使った原因を予測するモデルを利用しているため生成AIよりも精度が高い

### 解決出来ること
計算途中のミスのポイントの傾向を発見することで勘違いしている部分を発見することができるので，数学の勉強をサポートすることができる．具体的には以下の3点が挙げられる.
- **生徒のつまずきを具体的に把握できる**  
  正誤や合計点だけでは分かりにくい、計算規則や考え方の理解不足を、答案の根拠とともに確認できる.
- **復習・宿題を選ぶ際の迷いや負担を減らせる**  
  苦手要素に応じた確認問題や復習候補を提示し、生徒の状況に合う課題を選びやすくする.
- **講師の経験による指導のばらつきを抑える手がかりになる**  
  「苦手要素の確認→復習→類題での理解確認」という共通の手順を示し、経験の浅い大学生講師でも指導を組み立てやすくする.
